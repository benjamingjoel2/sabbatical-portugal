# Ambient audio: PLACEHOLDERS

These four loops are **synthetic placeholders** generated by `scripts/synth-ambience.py`
(filtered noise and sine tones only; no recordings, no samples, nothing to license).

| File | Intended final sound |
|---|---|
| `atlantic-waves-PLACEHOLDER.mp3` | Atlantic waves on a Portuguese beach |
| `cafe-terrace-PLACEHOLDER.mp3` | A café terrace: murmur, cups, a distant espresso machine |
| `harbor-gulls-PLACEHOLDER.mp3` | Harbor gulls and rigging |
| `tram-bells-PLACEHOLDER.mp3` | Lisbon tram bells and rumble |

## Replacing them
1. Use only audio you recorded yourselves or have a licence for (keep the licence on file).
2. Export ~30 s seamless loops, mono, 64–96 kbps MP3.
3. Drop them in this folder and update the paths in `components/sound/SoundProvider.tsx` (`ambientLayers`).

Audio is **off by default** and only starts after a visitor answers "Yes" to the sound prompt
or presses the wave icon.
